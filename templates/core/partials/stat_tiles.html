{% comment %} The stat bar, shared by Oversigt and Projekter. Counts come from core.views._stat_context and are organization-wide on both pages. Colour is not decoration here: each of the three registration tiles carries the same hue as the status badge it counts — red for overskredet, amber for åben, blue for løst — so a number and a badge that mean the same thing look the same. Aktive projekter is deliberately neutral, because it isn't a status. The three status tiles link to Registreringer pre-filtered; the project count doesn't, because there's no matching filter on the projects list and a link that lands somewhere unfiltered would be a small lie. {% endcomment %}
